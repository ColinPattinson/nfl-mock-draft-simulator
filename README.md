# NFL Mock Draft Simulator

A visual NFL mock draft simulator built for streamers and content creators, designed to make live draft content look clean and engaging.

## Live site
Coming soon via GitHub Pages.

## Current scope
- Round 1 only
- 32 teams in the correct 2026 draft order
- Top 150 prospects
- Drag and drop draft board
- Team cards with logos and pick numbers
- Player cards with name, position, school and image

## Tech
- HTML
- CSS
- JavaScript
- GitHub Pages

## Local preview
Open `index.html` in a browser, or run a local static server.
